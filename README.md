# DSE 文言文自主學習平台（DSEClassicalChinese）

以 Duolingo 式遊戲化學習為設計核心，聚焦**文言字詞與句式**的自主複習平台。
內容以 DSE 12篇指定範文為主要例句來源，並擴充 12篇以外的常見文言例句。

## 專案結構
- `data/` — CSV 內容範本（篇章資料、知識點、題目、文言語法起點資料、虛詞對照表）
- `scripts/` — Firebase 匯入腳本
- `functions/` — SM-2 間隔重複複習排程 Cloud Function
- `public/` — 前端練習頁面原型（Cloudflare Pages 部署目錄）
- `wrangler.toml` / `package.json` — Cloudflare Pages 部署設定

## 核心設計
- **知識架構**：以字詞（一詞多義、詞類活用、古今異義、通假字、18個虛詞）與句式
  （判斷句、被動句、省略句、倒裝句）為主軸，範文只作例句來源標籤
- **複習引擎**：SM-2 間隔重複演算法，依答題表現動態安排下次複習時間
- **題型設計**：字義選擇、句子重組（拖曳還原語序）、配對題、填空默寫（含容錯比對）、
  判斷句式題、語譯選擇、詞類活用標記，共七種互動題型
- **遊戲化機制**：XP、全站單一 Streak、技能樹分層、跨篇成就徽章
