# Manjingo Classical Chinese Curriculum v1

## 1. 產品定位

Manjingo 的核心不是「12 篇指定文言篇章溫習」，而是建立可遷移到陌生文言篇章的語言能力。

學生完成一個技能後，應能在**未讀過的句子或短篇**中運用它，而不只是記得某篇課文的意思、主旨或標準答案。

核心原則：

1. **能力先於篇章**：knowledge point 以字詞、虛詞、句式、閱讀策略、翻譯策略為主。
2. **例句跨來源**：同一技能必須使用不同作者、不同篇章、不同語境的例句。
3. **陌生語境驗證**：真正掌握的標準，是學生能在未見過的句子中辨認或運用該技能。
4. **指定篇章降為素材**：十二篇可以提供高質例句，但不再決定核心 curriculum。
5. **文章內容理解分流**：主旨、人物、情節、思想內容移到 optional reading / exam mode，不佔一般 daily plan。
6. **避免表面防重**：questionId 不同但原句相同，仍視為高度重複；日後排程須考慮 source sentence / semantic pattern。

此方向與教育局文言學習建議一致：文言學習應幫助學生掌握常見文言字詞和句式，並透過語境和不同材料建立遷移能力，而不只是篇章記憶。

參考：
- 香港教育局《中國語文課程和評估指引（中四至中六）》補充說明：文言學與教應結合選篇特點，幫助學生掌握常見文言字詞、句式，以及古漢語詞彙、一詞多義、詞類活用、虛詞等。
- 香港教育局《中學中國語文建議學習重點》及相關課程文件。

## 2. Daily Learning 目標比例

一般模式每 10 題建議：

- 7–8 題：語言能力（字詞／虛詞／句式／翻譯策略）
- 2–3 題：陌生語境或短段綜合遷移
- 0 題：純指定篇章內容記憶

只有在學生主動進入「指定篇章／考試溫習模式」時，才大量出現篇章主旨、人物、情節、名句背誦等題目。

## 3. Curriculum strands

### A. Lexicon 詞彙與語義

核心能力：

- `lex.context-inference`：利用上下文推斷實詞義
- `lex.polysemy`：一詞多義
- `lex.ancient-modern`：古今異義
- `lex.word-class-shift`：詞類活用
- `lex.causative`：使動用法
- `lex.intentional`：意動用法
- `lex.tongjia`：通假／文字對應
- `lex.semantic-role`：依句法位置判斷詞性與語義功能

高頻實詞不應綁死在指定篇章。例如「去、窮、許、微、謝、顧、固、亡、間、故、安、卒、數、曾、徒、勝、鄙」等，可建立跨語境 lexical entries，再掛到上述能力之下。

### B. Function Words 虛詞

第一期核心：

- `fw.zhi` 之
- `fw.er` 而
- `fw.yi` 以
- `fw.yu` 於
- `fw.qi` 其
- `fw.wei` 為
- `fw.zhe` 者
- `fw.suo` 所
- `fw.ze` 則
- `fw.nai` 乃
- `fw.qie` 且
- `fw.hu` 乎
- `fw.yan` 焉
- `fw.ye` 也

每個虛詞下面再按功能拆分，而不是把整個字當一個單一知識點。例如 `fw.yi` 至少要區分原因、工具／憑藉、目的、處置等。

### C. Syntax 文言句法

- `syn.judgment` 判斷句
- `syn.passive` 被動句
- `syn.object-fronting` 賓語前置
- `syn.adverbial-postpose` 狀語／介詞結構後置
- `syn.attributive-postpose` 定語後置
- `syn.ellipsis-subject` 主語省略
- `syn.ellipsis-object` 賓語／介詞賓語省略
- `syn.negative-patterns` 否定結構
- `syn.interrogative-patterns` 疑問結構
- `syn.fixed-patterns` 常見固定格式

判斷標準不是能否背出某條名句，而是能否：

1. 辨認結構；
2. 找出被提前／省略／後置的成分；
3. 還原較自然語序；
4. 在陌生句子重做一次。

### D. Reading Strategies 閱讀策略

- `read.sentence-core` 找主幹：誰／做甚麼／對誰
- `read.referent-tracking` 代詞與省略主語追蹤
- `read.logical-relation` 因果、轉折、承接、假設、並列
- `read.parallel-inference` 利用對偶／平行結構推義
- `read.context-clues` 上下文語義線索
- `read.actor-tracking` 多人物敘事中的施事者追蹤
- `read.unknown-word-tolerance` 不依賴逐字全懂仍能掌握句意

### E. Translation 翻譯

- `trans.lexical-fidelity` 關鍵實詞落實
- `trans.function-word` 虛詞處理
- `trans.reorder` 倒裝還原
- `trans.supplement` 省略補足
- `trans.ancient-modern` 古今義轉換
- `trans.fluency` 在不增義的前提下譯成自然現代漢語
- `trans.integrated` 綜合翻譯

### F. Transfer 陌生語境遷移

- `transfer.single-sentence` 單句陌生語境
- `transfer.sentence-pair` 兩句互證
- `transfer.micro-passage` 3–5 句小段
- `transfer.short-passage` 短篇閱讀
- `transfer.mixed` 字詞＋句式＋翻譯混合任務

Transfer 題不是另一個「內容章節」，而是用來檢驗前面技能是否真正可遷移。

## 5. Question schema 新要求

未來 active core question 建議加入：

```js
{
  id,
  skillId,          // 新 curriculum skill，例如 fw.yi.reason
  kpId,             // 過渡期保留 legacy mastery mapping
  sourceTextId,     // 來源篇章；只作 metadata
  sourceSentenceId, // 同一句／近同句防重
  sourceKind,       // set-text | classical-canon | historical | constructed
  transferLevel,    // 0=直接辨識, 1=近遷移, 2=陌生語境, 3=短段綜合
  languageFocus,    // lexicon | function-word | syntax | reading | translation
  q, o, a, explanation
}
```

重要：`sourceTextId` 不再等於 curriculum 分類。

## 6. 題庫品質與多樣性門檻

每個核心 skill 至少應有：

- 6 題可用題目才進 production daily plan
- 至少 3 個不同 source texts
- 至少 2 題為非十二篇來源或真正陌生語境
- 同一 source sentence 不超過該 skill 題庫的 25%
- 不以單一篇章主旨知識作為答題前提

成熟 skill 的理想門檻：10–20 題，跨 5 個以上來源。

## 7. 排程原則 v1

新的 daily planner 應以 `skillId` 而不是文章排列：

1. 到期複習 skill
2. 弱項 skill
3. 新 skill
4. 在選題階段加入 source diversity constraint
5. 同一 source text 一般每 10 題最多 2 題
6. 同一 source sentence 短期內最多 1 題
7. 錯題後優先用「同技能、不同例句」驗證，再考慮回到原題

如此可保留 spaced repetition，同時避免「因為某篇文章的 knowledge points 多，所以整天都看到同一篇」。

## 8. 遷移階段

### Phase 1 — taxonomy foundation

- 建立機器可讀 curriculum taxonomy
- 標記 legacy kp 的去向
- 不改 production daily plan

### Phase 2 — question metadata migration

- 加 `skillId / sourceSentenceId / transferLevel`
- 把現有可遷移題移到新 skill
- 純篇章理解題標記為 optional content

### Phase 3 — transfer-first question expansion

優先擴充：

- 之、而、以、於、其、為
- 判斷、被動、賓語前置、省略、狀語後置
- 一詞多義／古今異義／詞類活用
- 陌生語境詞義推斷
- 綜合翻譯

### Phase 4 — planner switch

- daily plan 改用 skill taxonomy
- source diversity / sentence diversity 生效
- 舊 mastery 做 migration / alias mapping

### Phase 5 — optional set-text mode

- 十二篇內容理解保留為獨立模式
- 不影響一般語言學習路徑 mastery

## 9. Definition of Done

Curriculum v1 真正完成時，應能做到：

- 新學生連續學習數天，不會因 catalog 順序而集中在《岳陽樓記》
- 學生答錯「以＝原因」後，下一次優先看到另一個語境，而不是同一原句換問法
- mastery 能表述為「掌握 `以` 的原因義／目的義」而不是「掌握《岳陽樓記》」
- 一般 daily learning 幾乎不需要學生預先讀過十二篇
- 短篇陌生文言的表現可以由底層 skill mastery 解釋
