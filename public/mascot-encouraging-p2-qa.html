專門驗收答錯後的小墨靈。先看是否仍像同一角色，再看是否自然傳達「一起看清這一步」，並特別排除失望、責備、羞恥或無助感。

Gate A / C / D · all-ink neutral vs encouraging

34 / 42px 是產品實際 feedback 寬度；48 / 64 / 96 / 160px 是 artwork QA 尺寸。兩側使用同一套全墨角色 DNA：炭灰至深墨藍漸變、豆豆眼、淡腮紅、金色雲紋、流動墨冠與獨立墨滴。左側 neutral 候選保持置中、雙手放低；右側 encouraging v4 以前傾、開掌及隨動作偏轉的墨冠增加支持意圖。此對照只作 Gate A 驗收，尚未替換正式 neutral。

人工檢查

  • 眼神朝向學生／前方，不低頭、不皺眉。
  • 輕微前傾與開放手勢讀成「陪你再看」，不是指責。
  • 34 / 42px 時至少眼神、嘴形或伸手方向仍成立。
  • 沒有眼淚、汗滴、紅叉、聳肩、搖頭或失望姿勢。
  • 與全墨 neutral 候選相比，encouraging 的前傾、開掌及偏轉墨冠清楚增加支持意圖。
  • 墨冠像液態身體的一部分隨姿勢轉動，不像固定帽子。
