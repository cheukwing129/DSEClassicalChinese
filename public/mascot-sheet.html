小墨靈角色檢查表

一次檢查六個正式狀態在 32 / 48 / 64 / 96 / 160px 的輪廓、辨識度、一致性及 artwork readiness。此頁直接使用 production mascot runtime。

v1 · runtime-backed
Artwork 狀態：baseline-approved 表示角色基準已確認；placeholder-treatment 是 baseline 衍生暫代圖；candidate 表示已有獨立新 artwork、正等待人工 Visual QA；provisional 表示可用但稍後仍會深化；production 才是正式驗收完成。32px 一律使用 head crop。

人工 QA 檢查重點

  • 32–48px：第一眼仍辨認為同一個小墨靈，不靠文字才能認出角色。
  • 64–96px：happy / encouraging / thinking / determined 的差異要能在靜態畫面成立。
  • 160px：celebrate 可以最有動勢，但不可因裝飾蓋過角色輪廓。
  • Production artwork 不可只靠 overlay、顏色或動畫傳達狀態。
