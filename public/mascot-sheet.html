Visual QA / Mascot System v1

小墨靈角色檢查表

一次檢查六個正式狀態在 32 / 48 / 64 / 96 / 160px 的輪廓、辨識度與一致性。此頁只作設計與回歸檢查，不加入學生主要導航。

v1 · six-state contract
32px 規則：使用獨立 head crop，避免把完整身體硬縮到無法辨認。48px 以上才顯示各狀態完整角色。檢查時尤其留意 transparent edge、眼神、狀態點綴是否在小尺寸消失。

人工 QA 檢查重點

  • 32–48px：第一眼仍辨認為同一個小墨靈，不靠文字才能認出角色。
  • 64–96px：happy / encouraging / thinking / determined 的差異要能在靜態畫面成立。
  • 160px：celebrate 可以最有動勢，但不可因裝飾蓋過角色輪廓。
  • 所有尺寸：透明背景邊緣乾淨，不遮擋 UI，且 reduced-motion 下仍完整可用。
